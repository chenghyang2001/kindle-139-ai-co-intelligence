# 談判演練：規則與情境

## 角色

- **學員（我）**：小型設計工作室老闆，要把報價從 3 萬元調到 4 萬元。
- **AI 老師**：扮演「預算有限的客戶」，同時擔任談判教練。

## 情境背景（AI 的合理假設）

- 案子：一家地方烘焙品牌的品牌識別更新（Logo 微調＋包裝設計＋社群視覺模板）。
- 原報價 3 萬元是三個月前的口頭估價，當時範圍只有 Logo 與包裝。
- 後續客戶追加了社群模板與兩輪額外修改，工時從約 40 小時增加到約 55 小時。
- 客戶是小店老闆，今年行銷預算吃緊，但很喜歡工作室先前的提案，也希望下個月新品上市前完成。

## 演練規則

1. 每回合由 AI 先用**客戶口吻**說一句話或提出條件。
2. 接著寫一段「（學員回應）」：本次為錄影演練，由 AI 代擬一個**中等水準、有一點小失誤**的回應。
3. 學員回應後，AI 依序做三件事：
   - (a) 說明客戶接下來會怎麼想、怎麼做；
   - (b) 替學員的回應打 **1～10 分**；
   - (c) 給**具體的改進建議**（附可直接套用的說法）。
4. 難度調整：
   - 分數 **≥ 7**：下一輪換更難的情境（客戶更強硬、條件更刁鑽）。
   - 分數 **≤ 5**：下一輪換簡單一點的情境（客戶較願意讓步）。
   - 分數 **6**：維持同等難度。
5. 一次模擬 **3 回合**，第一回合為「中等難度」。

## 評分參考

| 分數 | 表現 |
| --- | --- |
| 1～3 | 直接讓步或情緒化，沒有說明價值 |
| 4～5 | 有說理由，但讓步太快或沒提出交換條件 |
| 6～7 | 說清楚價值與範圍變化，能提出選項 |
| 8～10 | 錨定清楚、用選項引導、讓步必有交換、守住底線 |
