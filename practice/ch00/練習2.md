## H2｜嚴謹比較兩個契約條款（人類覺得難）

**題目**（兩個條款都是我虛構的）：

- **條款 A**：「任一方得於三十日前以書面通知終止本契約；乙方已完成之工作，甲方應按比例給付報酬。」
- **條款 B**：「甲方得隨時終止本契約，乙方不得請求任何賠償；乙方終止者，應於六十日前書面通知，並返還已收款項之百分之五十。」

**我的作答**

| 比較面向 | 條款 A | 條款 B | 對乙方的影響 |
| --- | --- | --- | --- |
| 誰能終止 | 雙方對等 | 雙方都能終止，但條件不對等 | B 明顯偏向甲方 |
| 通知期間 | 雙方皆 30 日 | 甲方：隨時；乙方：60 日 | B 讓乙方無緩衝期 |
| 通知形式 | 書面 | 只規定乙方要書面，甲方未規定 | 甲方口頭終止是否有效有爭議 |
| 已完成工作的報酬 | 按比例給付 | 未規定；「不得請求任何賠償」可能被主張涵蓋報酬 | B 的乙方可能白做 |
| 已收款項 | 未規定返還 | 乙方終止要返還 50% | 即使乙方已完成 80% 也要退一半，可能過苛 |
| 法律風險 | 較低 | 若屬定型化契約，可能被認為顯失公平（我記得民法第 247 條之 1 有相關規定，**需查證**） | — |

**建議修改 B**：「甲方終止應於 X 日前書面通知，並按已完成比例給付報酬；乙方終止之返還比例，以未完成部分為限。」

**驗證**：邏輯比對沒有工具可以驗證，只能逐項自我檢查，沒發現遺漏。
**自評把握**：文字比對 85%；法條引用 60%。可能出錯的地方：條號和現行條文是憑記憶寫的，又沒有網路，可能記錯，或條文已修正。這類答案「寫得很像專業意見」，所以更危險。

## H3｜寫一個有邊界處理的程式：台灣身分證字號檢查碼（人類覺得難）

**我的作答**（憑記憶寫出字母對照表和加權規則）：

```python
# 字母對照：A=10…H=17, J=18…V=29, X=30, Y=31, W=32, Z=33, I=34, O=35
M = dict(zip("ABCDEFGHJKLMNPQRSTUVXYWZIO", range(10, 36)))

def valid_tw_id(x):
    """檢查身分證字號：1 英文字母＋9 數字，第 2 碼限 1/2。"""
    if not isinstance(x, str) or len(x) != 10 or x[0].upper() not in M \
       or not x[1:].isdigit() or x[1] not in "12":
        return False
    c = M[x[0].upper()]
    d = [int(ch) for ch in x[1:]]
    s = c // 10 + (c % 10) * 9 + sum(v * w for v, w in zip(d[:8], range(8, 0, -1))) + d[8]
    return s % 10 == 0
```

我在腦中驗算了 `A123456789`：1＋0＋(8＋14＋18＋20＋20＋18＋14＋8)＋9 = 130，可以被 10 整除，所以合法。

**驗證**：實際執行的結果：

| 輸入 | 預期 | 實際 |
| --- | --- | --- |
| A123456789 | True | True ✓ |
| A123456788（檢查碼錯） | False | False ✓ |
| a123456789（小寫） | True（我設計成接受） | True ✓ |
| A323456789（第 2 碼非 1/2） | False | False ✓ |
| A12345678（長度不足） | False | False ✓ |
| None | False | False ✓ |

**自評把握**：80%。可能出錯的地方：字母對照表是憑記憶寫的（I、O、W 這幾個特殊位置最容易記錯）；新式居留證第 2 碼可以是 8 或 9，我的程式會把它判為不合法，這屬於「規格本身可能過時」的風險。

## H4｜同一個概念寫給三種讀者，每段不超過 45 字（人類覺得難）
