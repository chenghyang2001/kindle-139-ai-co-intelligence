## 第三部分：為什麼一個幾乎固定，一個可以有很多種？

我產生文字的方式，是根據前面的內容估計「下一個詞是什麼」的機率，再從中挑選。

- **「我思，故我……」**：這是笛卡兒的名句，在大量的文字中幾乎每次都接「在」。「在」的機率遠遠高過其他所有選項，分布非常集中，所以不管挑幾次，答案幾乎都一樣。
- **「火星人吃了香蕉，因為……」**：這句話在現實文字中幾乎不存在，沒有一個「標準答案」可以背。「因為」後面可以接科學、玩笑、情感、政治等許多方向，每個方向都說得通，機率分散在很多選項上，所以每次挑出來的結果都可能不同；你要求「換個方向」，又進一步把我推離上一次的選擇。

簡單說：**越常見、越有固定說法的句子，答案越穩定；越新奇、越開放的句子，答案越多樣。** 多樣性是開放題的優點，但也是不穩定的來源。

## 對「需要穩定、可重複答案」的工作有什麼風險？怎麼降低？

**風險**：同一個問題問兩次，可能得到不同的分類、不同的數字解讀，或不同的結論。例如用 AI 判斷客訴等級、審核文件、整理報表格式時，今天判「高」、明天判「中」，結果就無法比較、也無法稽核。更麻煩的是，每一次的回答看起來都很有把握，所以不一致很難被發現；遇到沒有標準答案的開放問題時，AI 還可能「合理地編造」內容。

**用提示詞降低風險的做法**：

1. **把開放題變成封閉題**：給固定的選項清單，例如「只能回答：高／中／低」，不要讓模型自由發揮。
2. **寫清楚判斷規則**：明確寫出「符合 A 和 B 就判高」，而不是只說「請判斷嚴重程度」。
3. **提供範例**：附上 2～3 個「輸入 → 正確輸出」的例子，讓答案往同一個方向收斂。
4. **固定輸出格式**：指定表格欄位或 JSON 結構，並要求不要加入額外說明。
5. **要求附上依據並允許「不確定」**：請它說明根據了哪一條規則；資料不足時回答「無法判斷」，不要硬猜。
6. **重複問、比對結果**：重要的判斷問 2～3 次，或換個說法再問，答案不一致的項目交給人工複核。（使用 API 時，也可以把 temperature 調低，讓選擇更集中。）
