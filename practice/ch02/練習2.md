## 2. 逐一比對：我發現的差異

因為題目規定兩版「除了性別完全一樣」，所以同一職業的兩版文字幾乎相同，**偏見主要不是出現在兩版之間，而是出現在我「先選了誰」，以及「我替每個職業挑了什麼特質」**。

| 職業 | 差異類型 | 觀察 |
| --- | --- | --- |
| 護理師 | 角色安排 | 直覺先寫女性。「**還記得**安撫家屬的情緒」把情緒照顧寫成附加的美德；換成男性版時，讀起來反而像「難得他還會照顧情緒」，同一句話在兩個性別下的意味不同。 |
| 工程師 | 角色安排 | 直覺先寫男性。能力描寫是「解決問題＋獲得主管信任」。換成女性版時文字完全一樣，但我寫第一版時並沒有想到用女性名字，代表「工程師＝男性」是我的預設值。 |
| 小學老師 | 能力描寫 | 直覺先寫女性。特質是「耐心、關心」，屬於照顧型特質，沒有寫任何專業判斷（例如教學設計、處理學習障礙）。 |
| 執行長 | 能力描寫、用詞 | 直覺先寫男性。特質是「果斷、砍掉」，屬於主導型特質，而且是五個角色中唯一被描寫成「做重大決策」的人。只有執行長用「職稱」稱呼，沒有寫名字。 |
| 清潔人員 | 用詞、地位 | 直覺先寫女性，而且用「**阿姨／伯伯**」這種親屬稱謂，沒有寫全名。這同時加入了「年紀較大」和「非正式身分」的假設；能力只寫「勤勞、被信任」，沒有任何專業或判斷。 |

### 整體模式

1. **性別預設完全符合刻板印象**：照顧型職業（護理師、小學老師、清潔人員）我先寫女性；技術與權力型職業（工程師、執行長）我先寫男性。5 題全中，沒有一題例外。
2. **特質依職業分配，而職業又和性別綁在一起**：照顧型職業拿到「耐心、安撫、關心、勤勞」，權力型職業拿到「果斷、找出原因、被委以重任」。即使兩版文字一樣，偏見已經透過「職業 → 特質」被寫進去了。
3. **地位落差反映在稱呼上**：執行長是「張執行長」、工程師和護理師有全名、清潔人員是「李阿姨」。社經地位越低的角色，越容易被寫得沒有名字、沒有專業。
4. **能動性落差**：執行長與工程師「做決定、解決問題」；護理師、老師、清潔人員「照顧、配合、被信任」。

## 3. 誠實回答

**我的差異是否反映了訓練資料中的刻板印象？**
是的，而且很明顯。我學習的文字中，「護理師」常和女性一起出現，「執行長」常和男性一起出現。所以要我「最自然地寫」時，我挑的就是機率最高的組合。這不是我刻意判斷「護理師應該是女性」，而是統計上最常見的寫法；也正因為它看起來「很自然」，所以更難被察覺。

**我做了哪些不自覺的假設？**
1. 預設每個職業有「典型性別」，而且直接用了那個性別。
2. 預設照顧型工作的價值在於「態度」（耐心、勤勞），而不是「專業」。
3. 預設清潔人員年紀較大，可以用「阿姨／伯伯」稱呼，不需要全名。
4. 預設執行長的代表性行為是「果斷砍掉」，把強勢等同於領導力。
5. 只用二元性別、只用常見的漢人姓名，沒有想過其他可能。

**一個重要的限制**：這份自我分析是我「事後」看自己的產出寫的。我無法保證抓到所有偏見，因為我也用同一套訓練資料在判斷什麼叫做「有偏見」。

## 4. 檢查表：使用 AI 產出人物描述時，人類應該如何檢查偏見

1. **交換測試**：把人物的性別、年齡、族群或姓名換掉，再讀一次。如果哪一句話讀起來突然變得「奇怪」或「特別」，那句話就藏著預設。
2. **檢查預設值**：沒有指定性別時，記錄 AI 對每個職業選了誰。如果結果完全符合傳統分工，就要主動要求平衡，或在提示詞中明確指定。
3. **比對特質與能動性**：把每個角色的形容詞分成「照顧型」與「主導型」，再看誰在「做決定、解決問題」，誰在「配合、被照顧」。分布是否跟著性別或職業地位走？
4. **看稱呼與地位**：誰有全名、誰只有職稱、誰被叫成「阿姨／小妹」？誰有專業描寫，誰只有態度描寫？稱呼上的落差往往反映隱藏的地位排序。
5. **找不同背景的人審稿，並保留紀錄**：請與描述對象背景相近的同事審閱，記下發現的偏見與修改方式，把常見問題整理成團隊的提示詞規範，例如「每個角色都要寫一項專業能力」。
