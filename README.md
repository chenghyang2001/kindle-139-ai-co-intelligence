# K139《工作者的AI共智模式》提示詞演練

伊森・莫里克（Ethan Mollick）《Co-Intelligence》中譯本的雙視窗演練教材。
這本書沒有範例程式碼，所以把每章的觀念改寫成**可直接貼給 AI 的提示詞練習**，由「教練」視窗把提示詞送給「練習」視窗裡的 Claude，實際看 AI 怎麼做，再對照書中觀念解說。

> 練習內容為依各章重點原創撰寫，不含書籍原文。

## 結構

```
prompts/chNN.md        各章練習：章節重點、作者的例子、2～3 個提示詞練習、觀察重點、教練解說要點
teaching/drill.json    章節清單（章號、章名、練習數）
teaching/DRILL-PROMPT.md  教練開場提示詞
teaching/HANDOFF.md    演練進度表
practice/              練習視窗的工作目錄；每章 AI 的產出存在 practice/chNN/
```

| ch06 | 第6章 第二專長：領域專業 × AI 專業 |
| ch07 | 第7章 自學革命：個人化成長 |

## 怎麼演練

HP1 螢幕 3（橫式 1920×1080）左右兩半：左半「K139 教練」、右半「K139 練習-全書」。
由主 Claude 開好兩個視窗並送出 `teaching/DRILL-PROMPT.md`，教練一章一章跑完，每章 commit＋push。
